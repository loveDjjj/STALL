\begin{abstract}
全生成视频检测需要在生成器快速迭代、监督样本滞后和视频伪影高度局部化的条件下保持泛化能力。近期 \stall 提出以真实视频校准的空间--时序似然检测生成视频，避免使用生成样本训练分类器，并在 DINOv3 全局帧表征上联合建模帧级外观和帧间变化。然而，全局帧向量会压缩空间位置，小范围纹理闪烁、边缘跳变和局部形变不连续可能在全局汇聚后被稀释。本文提出 \method，一种在 \stall 协议内扩展局部证据的免训练检测方法。\method 使用同一冻结 DINOv3 编码器同时提取全局 token 和 patch token，在真实视频上分别建立全局似然、局部空间似然和同网格二阶 patch 时序似然；局部空间与局部二阶时序证据先形成统一局部分数，再与全局 \stall 分数进行评测前冻结融合。该设计保留了真实视频校准和单视频推理的边界，同时使检测器显式关注局部时序加速度偏离。当前 release 在 ComGenVid、VideoFeedback 和 GenVideo 上分别取得 0.9198/0.9211、0.8628/0.8750 和 0.8374/0.8283 的平均 AUC/AP；相对 global-only 分支，生成器宏平均 paired bootstrap 的 $\Delta$AUC 在三个数据集上均为正。进一步的组件消融、二阶/高阶导数对照、真实校准数量分析和验证式融合实验表明，主要增益来自局部二阶时序证据，patch 分支需要足够且有代表性的真实视频校准，alpha-only 验证选参是比固定权重更稳妥的部署适配策略，而空间尺度和聚合方式构成方法的实际边界。
\end{abstract}
