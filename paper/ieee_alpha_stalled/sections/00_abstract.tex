\begin{abstract}
全生成视频检测需要在未知生成器下兼顾全局外观偏移和局部时序异常。STALL 通过真实视频校准的全局空间--时序似然实现免训练检测，但单帧全局表征可能压缩局部动态异常。本文提出 Alpha-STALLED U0，在冻结 DINOv3 上保留 STALL 的全局空间与一阶时序分支，并加入同网格 patch token 二阶差分似然。U0 对每个视频确定性均匀采样三个 2 秒窗口，每个窗口使用 8 FPS 下 16 个互异帧，分别计算全局分数 $G_k=0.5G_{s,k}+0.5G_{t1,k}$ 和局部分数 $L_k=0.1L_{s,k}+0.9L_{D2,k}$；窗口分数在分支内取均值，并按有效窗口数用独立真实视频经验分布重新校准，最终得到 $S=0.6G+0.4L$。该协议不使用生成视频拟合白化、经验分布、阈值或融合权重。在 ComGenVid、VideoFeedback 和 GenVideo 的固定 21,421 视频交集上，U0 分别取得 0.8968/0.9064、0.8597/0.8689 和 0.8657/0.8416 的 AUC/AP，Macro-3 为 0.8741/0.8723；相对原版 STALL 提高 0.0353/0.0295，相对统一单窗口实现提高 0.0109/0.0087，后者的 Macro AP 增益 95\% 区间为 [0.0057,0.0120]。扩展到全部 23 个生成器和 45,185 条生成视频后，U0 相对原窗口 STALL 的 All-23 AUC/AP$_{\rm fake}$/AP$_{\rm real}$ 仍提高 0.0338/0.0383/0.0288。在锁定后的 GenVidBench 确认实验中，U0 相对 STALL 和统一单窗口的 AP 分别提高 0.0460 和 0.0126。系统消融和原窗口因子分解表明，主要增益来自细粒度同网格 D2，三窗口覆盖提供较小但独立的贡献；K=5、下尾聚合、共同运动残差、多尺度 token、中间层特征和联合典型性均未达到预设准入标准。因此，最终方法保留两个分支、固定线性融合和目标域真实视频校准。
\end{abstract}
