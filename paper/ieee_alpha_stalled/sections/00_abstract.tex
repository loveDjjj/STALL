\begin{abstract}
生成视频检测需要在不依赖特定生成器训练样本的条件下，同时识别整体外观偏移与局部动态异常。STALL 通过真实视频参考统计对全局帧表征及其一阶差分建模，但单个全局向量可能压缩只出现在少数空间位置和时间步的异常。本文提出 Alpha-STALLED：保留 STALL 的全局空间与全局一阶时序证据，并在冻结 DINOv3 的 $14\times14$ patch token 网格上引入同位置二阶差分似然。最终方法经受控消融后只保留 Local D2，不使用 Local Spatial。每个视频在 8 FPS 下均匀选取至多三个 2 秒窗口；窗口级分数先在分支内聚合，再按有效窗口数使用互斥真实视频重校准，最终以固定 $0.6/0.4$ 权重融合 Global 与 Local。整个流程不使用生成视频拟合白化参数、经验分布或融合权重。在 ComGenVid、VideoFeedback 和 GenVideo 的 21,421 条视频交集上，本文方法的 AUC/real-positive AP 分别为 0.9015/0.9110、0.8621/0.8687 和 0.8586/0.8391，Macro-3 为 0.8741/0.8729。相对同协议 Global-only，Macro AUC/AP 提高 0.0218/0.0197；D2 相对 D1 提高 0.0022/0.0033；K=3 相对 K=1 提高 0.0060/0.0024。Spatial 分支在 Local 和完整模型中均造成稳定下降，因而被正式移除。GenVidBench Pair1 外部验证进一步表明 Local D2 提供显著 AUC 增益，但 K=3 与 K=1 在该外部集上没有可检测差异。结果支持真实视频校准的局部二阶证据与全局似然具有互补性，同时将结论限定在需要目标域真实参考视频的 training-free 场景。
\end{abstract}
