\section{引言}
\label{sec:introduction}

文本到视频和图像到视频生成模型正在快速提升视频质量、可控性和可访问性。高保真生成视频可以服务于创意生产和内容自动化，但也会放大错误信息、身份冒用和内容溯源风险。与传统 deepfake 检测不同，本文关注的是完全由生成模型合成的视频：每一帧都可能来自生成分布，检测器不能依赖被篡改区域与真实背景之间的局部拼接痕迹。

该任务的困难主要来自两个方面。第一，监督式检测器通常需要真实/生成标签和特定生成器样本，面对新生成器时容易出现分布外退化。第二，许多生成视频伪影不是静态单帧伪影，而是跨帧运动、纹理和局部结构变化的不连续。将图像检测器逐帧应用于视频会忽略这些时序证据，只使用视频级监督分类器又会把检测边界绑定到训练生成器。

\stall~\cite{benhayun2026stall} 为这一问题提供了重要基线。它不使用生成视频训练分类器，而是在真实视频校准集上估计 DINOv3 全局帧特征及其相邻帧差分的白化高斯似然，并通过经验百分位把空间证据和时序证据融合为单个真实性分数。该思路的优势在于协议清晰、训练自由、可解释且可跨生成器使用。但是，\stall 的表示单元是每帧一个全局向量。全局向量适合捕获整体外观和整体运动偏移，却可能压缩小范围局部证据。实际生成视频中常见的局部闪烁、物体边缘跳变、背景纹理漂移和局部形变突变，往往只影响少数 patch 和少数时间步。

本文提出 \method，在不改变 \stall 免训练设定的前提下，把真实视频似然建模扩展到 DINOv3 patch token。核心问题不是简单增加一个局部外观分支，而是判断局部 patch 轨迹是否符合真实视频的时序统计。为此，我们在同一空间网格上计算连续三帧 patch token 的二阶差分，并在真实视频上估计其白化似然。二阶局部时序特征刻画 patch 表征轨迹的加速度，能够反映一阶全局运动难以捕获的局部动态不连续。随后，局部空间证据和局部二阶时序证据先组合为统一局部分数，再与原版 \stall 全局分数融合。推理阶段不使用测试批次排序、生成器来源或真实/生成标签，因此输出分数仍对应单个未知视频的真实视频典型性。

本文的结构如下：先给出方法与评测协议，再报告主结果，随后用系统消融说明增益来源，最后讨论方法边界与适用条件。

本文的贡献如下：

\begin{itemize}
  \item 提出一种全局--局部真实视频校准框架，将 \stall 的全局空间--时序似然扩展到 DINOv3 patch token，而不引入生成视频训练。
  \item 提出同网格二阶 patch 时序似然，用局部特征轨迹加速度刻画生成视频中的局部动态不连续；统一核心消融确认 D2 是 Local 的主要有效项，代表性历史对照进一步排除了 lag-1、多滞后和更高阶导数替代项。
  \item 提出严格的三窗口视频级聚合：全局与局部分支分别对三个均匀 2 秒窗口取均值，并按有效窗口数使用独立真实视频经验分布重校准，避免长视频权重偏置和窗口数量造成的分布漂移。
  \item 在固定 21,421 视频交集上报告三数据集主结果、20 个生成器细分、video-level paired bootstrap 和校准规模稳定性，并用预设准入门槛排除 K=5、下尾聚合、共同运动残差、多尺度、中间层和联合典型性等未达标复杂化方向。
\end{itemize}
