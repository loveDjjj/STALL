\section{方法}
\label{sec:method}

\subsection{任务定义与总体流程}
给定视频 $V=\{I_t\}_{t=1}^{T}$，目标是输出真实性分数 $S(V)\in[0,1]$，其中较高分数表示视频更接近真实视频参考统计。检测器不使用生成视频训练分类器，也不在推理时读取生成器来源、测试标签或测试批次组成。Local 参数与经验分布仅由和评测集互斥的真实视频估计。

图~\ref{fig:pipeline} 展示了三个阶段。第一阶段加载官方 \stall VATEX Global 参数，并从目标域真实校准视频构建 Local D2 白化参数、窗口级经验分布和按有效窗口数分组的视频级经验分布。第二阶段对待测视频均匀选择至多三个互异的 2 秒窗口，每窗在 8 FPS 下包含 16 帧；冻结 DINOv3 同时输出 Global token 与 $14\times14$ patch token。第三阶段分别聚合 Global 与 Local D2 证据，执行视频级真实分位数校准，并以固定权重融合。

\subsection{冻结 DINOv3 表征}
所有分支共享冻结的 DINOv3 ViT-L/16 编码器~\cite{simeoni2025dinov3}。第 $t$ 帧得到 Global token $g_t$ 与 patch token 网格 $P_t$：
\begin{equation}
  g_t\in\mathbb{R}^{D},\qquad
  P_t=\{p_{t,i}\}_{i=1}^{N}\in\mathbb{R}^{N\times D},
  \label{eq:dino_features}
\end{equation}
其中 $D=1024$，$N=14\times14$。Global 序列用于 \stall 的空间与一阶时序证据，patch 序列只用于 Local D2。两类证据共享同一次编码器前向传播，不训练额外骨干网络。

\subsection{白化高斯似然与经验分位数}
对特征 $x\in\mathbb{R}^{d}$，真实参考样本给出均值 $\mu$ 与协方差 $\Sigma=U\Lambda U^\top$。保留正特征值对应子空间并构造
\begin{equation}
  W=U_r\operatorname{diag}\left((\lambda_1+\epsilon)^{-1/2},\ldots,(\lambda_r+\epsilon)^{-1/2}\right).
  \label{eq:whitening}
\end{equation}
白化特征与标准高斯对数似然为
\begin{align}
  z(x)&=(x-\mu)W,\\
  \ell(x)&=-\frac{1}{2}\left[r\log(2\pi)+\lVert z(x)\rVert_2^2\right].
  \label{eq:gaussian_ll}
\end{align}
设真实参考分数排序为 $\mathcal{C}_b=\{c_{b,j}\}_{j=1}^{M}$，任一统计 $q_b$ 的右闭合经验分位数为
\begin{equation}
  \widehat F_b(q_b)=\frac{1}{M}\sum_{j=1}^{M}\mathbb{I}[c_{b,j}\leq q_b].
  \label{eq:percentile}
\end{equation}
白化与似然使用 float64，DINOv3 特征保持 float32；经验分布使用稳定排序和右闭合并列规则。

\subsection{全局 \stall 分支}
对第 $k$ 个窗口，Global Spatial 逐帧计算 $\ell_{\mathrm{gs}}(g_t)$ 并取最大值；Global T1 对相邻帧差分进行 L2 归一化，计算似然后取最小值：
\begin{align}
  q_{\mathrm{gs},k}&=\max_t\ell_{\mathrm{gs}}(g_t),\\
  d_t&=\frac{g_{t+1}-g_t}{\lVert g_{t+1}-g_t\rVert_2},\\
  q_{\mathrm{gt},k}&=\min_t\ell_{\mathrm{gt}}(d_t).
\end{align}
Global 的白化参数与窗口参考分布固定使用官方 VATEX 资产。经分位数映射后，窗口分数为
\begin{equation}
  G_k=0.5\widehat F_{\mathrm{gs}}(q_{\mathrm{gs},k})+0.5\widehat F_{\mathrm{gt}}(q_{\mathrm{gt},k}).
  \label{eq:global_window_score}
\end{equation}

\subsection{同网格 Local D2}
Local 分支不包含单帧 Spatial 项。对连续三帧同一网格位置的 patch token，计算二阶差分并沿特征维归一化：
\begin{align}
  a_{t,i}&=p_{t+2,i}-2p_{t+1,i}+p_{t,i},\\
  \hat a_{t,i}&=\frac{a_{t,i}}{\lVert a_{t,i}\rVert_2},
  \qquad t=1,\ldots,T-2.
  \label{eq:patch_acceleration}
\end{align}
不使用显式 patch 匹配、区域池化或 CLS/register token。目标域真实 calibration patch 轨迹用于拟合 $\mu_{\mathrm{D2}}$、$W_{\mathrm{D2}}$ 与窗口参考分布。窗口内对全部时间与网格位置的似然取算术均值：
\begin{equation}
  q_{\mathrm{D2},k}=\operatorname{mean}_{t,i}\ell_{\mathrm{D2}}(\hat a_{t,i}),\qquad
  L_k=\widehat F_{\mathrm{D2}}(q_{\mathrm{D2},k}).
  \label{eq:local_window_score}
\end{equation}

\subsection{视频聚合与固定融合}
设有效窗口数为 $K_V\leq3$。两条分支分别取窗口均值：
\begin{equation}
  G_{\mathrm{raw}}(V)=\frac{1}{K_V}\sum_kG_k,\qquad
  L_{\mathrm{raw}}(V)=\frac{1}{K_V}\sum_kL_k.
  \label{eq:branch_video_mean}
\end{equation}
随后仅使用具有相同有效窗口数的目标域真实校准视频建立视频级经验 CDF，得到 $G(V)$ 与 $L(V)$。最终分数为
\begin{equation}
  S(V)=0.6G(V)+0.4L(V).
  \label{eq:final_score}
\end{equation}
每个校准视频在每个分支中只贡献一个视频级统计，避免长视频因窗口更多而获得更高权重。$K$ 与融合权重在三个开发数据集上确定，因此这些数据集属于开发与内部评测范围，而非未触碰的确认集。
