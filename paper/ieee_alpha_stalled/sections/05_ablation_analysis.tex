\section{消融与边界分析}
\label{sec:ablation}

本节按科学问题组织实验。除特别说明外，所有结果均采用相同的独立真实视频校准协议、相同的评测交集和相同的分数方向；单元格报告 AUC 与以真实视频为正类的 AP。

\subsection{全局与局部证据的互补性}
表~\ref{tab:component_ablation} 固定 $K=3$，分别移除全局或局部分支。融合模型在 Macro-3 上达到 0.8741/0.8723，超过仅全局分支的 0.8485/0.8486 和仅局部分支的 0.8357/0.8292。三个数据集的相对排序并不完全一致，但融合在宏平均上稳定受益，说明局部二阶证据提供了全局分支之外的互补信息。

\subsection{局部一阶与二阶时序}
表~\ref{tab:temporal_ablation} 在三个数据集上隔离局部时序的导数阶数。四组实验共享相同的编码器、窗口、区域大小、聚合方式、真实校准视频、局部空间分支、全局分支和融合权重；仅将局部时序从 D1 替换为 D2。D2 在仅局部时序和完整 LSTL 中均提高三个数据集的 AUC/AP；完整模型的 Macro-3 AP 增加 0.0028，配对 bootstrap 的 95\% 区间为 [0.0019, 0.0038]。

\subsection{时间覆盖}
表~\ref{tab:window_coverage_ablation} 先给出仅改变窗口数的受控比较：由 $K=1$ 到 $K=3$ 时，Macro-3 AUC/AP 分别提升 0.0109/0.0087。已有的 $K=5$ 与全部窗口扩展均未改善 AP，却显著增加帧数，因此本文采用三个均匀窗口。

\subsection{局部空间支持域}
表~\ref{tab:local_support_boundary} 显示最优图块区域大小随数据集变化：ComGenVid 偏好较大支持域，GenVideo 在中等支持域达到峰值，而 VideoFeedback 偏好细粒度图块。该差异表明区域大小与局部运动尺度相关，不能简单视为可跨数据集固定的常数。
