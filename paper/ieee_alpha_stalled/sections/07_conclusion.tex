\section{结论}
\label{sec:conclusion}

本文提出 \method，将 \stall 的真实视频校准似然从全局帧表征扩展到 DINOv3 patch token，并用同网格二阶 patch 时序似然捕获局部动态不连续。该方法保持免训练、真实视频校准和单视频推理边界，不使用生成样本训练分类器，也不依赖测试批次排序或生成器来源。三数据集主结果、组件消融、paired bootstrap 和高阶导数对照表明，局部二阶时序证据是 patch 分支的主要增益来源，并能在多数设置下补充全局 \stall 分支。与此同时，VideoFeedback 负迁移、region/aggregation 敏感性和真实视频误伤案例说明，该方法的适用边界主要来自局部异常空间尺度和真实视频域偏移。后续工作应优先补充同协议外部 baseline、严格外部校准源消融和更系统的扰动鲁棒性分析。
