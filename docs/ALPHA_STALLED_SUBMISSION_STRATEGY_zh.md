# Alpha-STALLED投稿组织方案：贡献、消融与证据表达

核对日期：2026-09-12。本文是基于当前最终数据的投稿建议，不修改检测模型、不重新选参数，也不是已经完成投稿的声明。论文完整证据稿仍为[MANUSCRIPT_REVISION_PLAN_zh.md](MANUSCRIPT_REVISION_PLAN_zh.md)。

最新进展：建议已落实到[IEEE中文正文](../paper/ieee_alpha_stalled/main.tex)。第11节补充本轮近期原文阅读与实际修订；新流程图按作者要求留空。模型、数据身份和主成绩未改变。

## 1. 建议继续用哪个方案

继续采用当前Alpha-STALLED：冻结DINOv3、目标Global＋同网格归一化Local D2、FC K3、独立VATEX百分位参考、0.5/0.5融合。当前23单元三域等权Average AUC/AP-real为**0.874/0.877**，不恢复旧20单元0.881/0.882，不以五次新参考池均值0.876/0.879替换单个冻结模型成绩。

这是一篇有明确表征问题和实证证据的算法研究。推荐中心问题为：

> 在不训练真假分类器的条件下，局部高维二阶变化经过真实统计测量，能否提供全局汇总及所测试局部标量统计尚未充分利用的信息？

当前最强证据是D2对D1的重复增量、匹配拟合位置数后相对pooled的优势，以及对同预算Global的平均AUC补充。目标真实适配和动态选窗是方法条件及控制因素，不预设为两个额外、同等强度的全新算法贡献。

## 2. “变化不大”要按实验职责解释

消融有两种职责：一是验证方法增加了有效能力；二是排除某个替代解释。只有第一种需要正向增益；第二种经常需要观察到变化很小。持平是否有价值，取决于它回答了什么问题。

| 实验与事实 | 科学角色 | 合适的处理 |
| --- | --- | --- |
| D2相对D1，原池+0.006/+0.007；新池+0.005/+0.007，区间均正 | 核心表示选择 | 小而重复的增量，放主要证据 |
| 位置数量匹配D2与256位置基本持平；匹配后仍比pooled约+0.020/+0.021 | 排除拟合位置数解释 | 支持优势并非仅由额外拟合观测产生 |
| 换Local均值、保持白化，几乎不变 | 机制诊断 | 降低均值适配的叙事权重，说明变化主要跟随度量 |
| 目标Global下，Local再换目标参考，增量区间跨零 | 参考协议控制 | 不把双分支目标适配都写成必要创新 |
| 源等权原池小幅提高，新池未重现 | 候选验证未通过 | 保留原模型，作为参考敏感性结果 |
| CRF23变化区间跨零，CRF35明确下降 | 处理条件边界 | 写测试条件下的敏感性，不写全面鲁棒 |
| 8帧短视频不同选择器完全一致 | 规则退化 | 说明只有一个合法窗口，不当成四次独立稳健性证据 |

如果某模块被移除或替换后没有明确影响，而它又承担论文的主要创新主张，就应缩小该主张或简化模块。不能将任何持平都统一改写成“鲁棒”“高效”或“不可替代”。

“区间跨零”不等于正式证明等价。现有位置数量控制的差值区间很窄，可以如实写“在所测设置下变化很小”；若没有事先确定的等效/非劣界，不追加正式等效结论。同理，保存向量从256减少到最多42，不等于端到端推理加速六倍：DINO观察帧数没有因此减少。

## 3. 当前最有说服力的证据链

这里保留未舍入数据供投稿取数，正文常规性能表仍用三位小数。差值是绝对AUC/AP变化，不是相对百分比。

| 核心比较 | ΔAUC及95%区间 | ΔAP-real及95%区间 |
| --- | --- | --- |
| 原池Full−同目标预算Global | +0.009442 [0.003452,0.015632] | +0.005338 [0.000124,0.010805] |
| 新视频池Full−同池Global | +0.009721 [0.004541,0.014939] | +0.003938 [−0.000885,0.008818] |
| 原池D2−D1 | +0.005686 [0.004472,0.006905] | +0.007222 [0.005982,0.008598] |
| 新视频池D2−D1 | +0.005348 [0.004127,0.006508] | +0.006528 [0.005423,0.007720] |
| 匹配拟合位置数的D2−pooled | +0.019965 [0.014727,0.025427] | +0.020755 [0.015063,0.026079] |

这可以组织成一条递进论证：

1. 同目标真实信息的Global上仍有Local增量，削弱“只是额外拿到目标real”的解释。
2. D2优于对应D1，表明在这个评分框架中二阶具有额外作用。
3. 提前平均Patch不如逐位置测量；匹配拟合位置数后增量仍在，削弱“只是拟合样本更多”的解释。
4. 更换真实拟合视频后，AUC补充与D2对D1的优势重复出现；AP补充更依赖参考条件。

原池D2对D1在23单元的AUC/AP点估计分别20胜3负、22胜1负，比只列Average更能说明阶次增量的覆盖面。对Global则是14胜9负、13胜10负；两种比较不应混为一谈。

区间条件于给定的真实参考或五套新池，源组配对重抽样不自动校正历史模型搜索。新池来自原有真实来源总体且允许彼此重叠，不是五个全新数据域。统计上的可检测差异也不自动证明部署价值：仍须如实交代目标real预算、误报和计算开销。

数据源：[原池差值](../results/paper_complete/confidence_intervals.csv)、[新池及位置匹配](../results/runs/reference_confirmation/results/contrasts.csv)、[逐生成器胜负](../results/runs/local_direction_evidence/generator_comparison_summary.csv)。

## 4. 如何让小增益清楚，而不放大数字

推荐同时提供绝对性能与增量区间。0.005686 AUC可写成**0.569个AUC百分点**，但不能写成5.686个百分点，也不必用相对百分比制造更大数值。

已由现有CSV生成[增量图PDF](figures/submission_evidence.pdf)、[PNG](figures/submission_evidence.png)及[逐点数据](figures/submission_evidence.csv)。横轴明确是百分点差，零线可见，完整区间均显示，原池与新池分开标记；新池AP和Uniform结果的跨零区间也保留。这张图适合回答“差异有多大、重复后是否仍在”，不把截断绝对分数柱状图作为主要视觉证据。

建议图注：**受控比较的效果量。** Local gain表示完整模型减同协议Global，除最后一行外采用FC观察。误差线为给定真实参考下的95%评价源组配对bootstrap区间；new pools为五个固定新拟合池的模型指标差均值，不是预测集成。横轴单位为AUC/AP百分点，未进行全部历史搜索的多重比较校正。匹配预算行使用原拟合池的对应位置数量控制。

正文建议保留三位小数，内部用未舍入值计算差值。显示并列只表示舍入后的并列；若0.000级的小差值不值得正文展开，可给“变化很小”和区间，而不是强行多加小数位将每行区分成最优。

同协议表可以标粗最佳值，色彩用于强调预定核心行或增量。红色不是学术论文的强制要求；跨协议的发表值与自算结果不宜通过同一套红色排名暗示已经公平超越。当前完整稿按用户原要求保留宽表和强调样式，投稿版的建议与原始材料分开处理。

## 5. 理论解释应加强到哪里

方法最清楚的解释是：D2选择时间关系，归一化减少幅度的直接作用，真实二次型决定哪些特征方向受到更大惩罚。对于同一组已归一化方向、同一度量与权重，令$E(u)=(u-\mu)^TA(u-\mu)$，有

$$\sum_i\omega_iE(u_i)=E(\bar u)+\sum_i\omega_i(u_i-\bar u)^TA(u_i-\bar u),\qquad\bar u=\sum_i\omega_i u_i.$$

因此逐位置测量保留了真实度量下的方向离散程度。它为“为何比较提前平均与逐位置评分”提供动机，是代数解释，不是新的性能定理。实际pooled控制还改变归一化位置并重新拟合Gaussian，不能由此恒等式直接断言实际分数或AUC必然更好。

避免物理加速度、物体轨迹、因果定位、真实性概率等超出当前实现的解释。同网格D2没有显式跟踪，完整协方差建模通道关系而非Patch邻接。SPLIT的TTR和LSMI也利用方向关系；我们的区别应是高维残差的真实统计测量，不能概括为“别人不看方向”。

## 6. 两项贡献的建议表述

**贡献一：局部动态方向的真实参考评分。**

> 我们在冻结视频表示上对逐位置归一化二阶残差进行真实统计测量，并将其与全局证据融合。在匹配真实信息与观察条件的控制中，该局部评分提供平均AUC补充；对一阶和提前空间聚合的比较进一步验证其表征选择。

**贡献二：对有效因素和适用边界的受控分析。**

> 我们通过拟合位置数匹配、独立新真实视频池、观察交互及固定窗口重编码对照，区分额外信息、统计支持和评分条件的作用，报告参考依赖及数据域反转。

第二项是实证认识与验证设计，不必伪装成另一套算法。目标域适配、CDF及FC K3是方法构成和适用条件；不为它们各自寻找一个必须大幅涨分的创新名额。

可以采用的标题方向为：**Alpha-STALLED：真实参考下的局部二阶动态方向检伪**。不在标题中先承诺普遍泛化、低误报保证、全新协方差算法或免目标域数据。

下面是一段可供重写摘要使用的中文草案，尚未覆盖现有正文：

> 冻结视觉表示上的生成视频检测需要确定哪些局部时间信息应被保留，以及如何由真实参考解释这些信息。本文提出Alpha-STALLED，在图块特征上测量归一化二阶残差的高维方向，并通过真实统计评分补充全局检测。三个基准23个生成器单元上的三域等权Average AUC/AP-real为0.874/0.877。在相同目标真实信息预算下，局部分支提高平均AUC；D2相对D1的增量在新真实拟合视频池中重复出现，匹配拟合位置数量后相对提前空间聚合的优势也得到保留。实验同时表明，AP增量、度量结构与观察策略具有条件依赖，较重重编码仍会造成性能损失。

摘要优先使用已经完成的新拟合视频证据，不能只挑旧池五次全部为正的扰动结果来概括稳定性。新池Full−Global只有AUC区间为正，AP跨零，应在摘要或主结果段明确。

历史外部结果也需保留身份边界：M30的当前形式目标Global＋Local在GenVidBench为0.862/0.863、ViF约0.589/0.592，不能取旧B3或对角版本在某域更好的行拼成统一方法。外部拟合预算不同，部分比较为旧协议；它们提醒我们不能声称已经解决普遍跨域泛化。M32原生XCLIP实验确实做过，但不等于当前23单元DINO/FC控制，不应为了赢得更大差距混表。

## 8. 对SPLIT比较和主表的具体建议

当前D2对TTR/SPLIT融合的Average领先较大，但AUC都只有12/23单元胜出，AP为11/23。ComGenVid在三域Average中占三分之一，其两个单元的大差值能够与其他单元的多次落后并存。

这支持当前协议下的宏平均比较，不支持“逐生成器普遍优于”。TTR在VideoFeedback的ModelScope单元达到0.967/0.971，D2为0.800/0.802；ComGenVid的TTR/SPLIT原始AUC又低于0.5。后者提示固定方向或域统计假设失配，并不意味着标量完全没有判别信息。二维Gaussian只检验了一个具体标量拟合方案，没有穷尽所有标量方法。

主表还应区分：

1. **发表值背景。** 原论文数字按其报告保留，不与我们不同身份/真实信息/平均口径的结果做配对因果解释。
2. **同协议归因。** 同DINO、同窗口、同目标真实预算下的Global/D1/D2/pooled等，承担主要贡献证据。

历史CSV中的`Average`可能表示23单元等权；当前论文的Average明确为三域等权，对应`paper_complete`中的`Macro-3`。其0.874不能改称原论文已经确认相同定义的Average。当前主表照录的发表Overall尚未统一核实，表名相同不能解决口径差异。

用户此前要求主表保留STALL Table 1形式的逐生成器宽表，本次不自动删除该表或恢复已删的复现列。若投稿版继续使用宽表，建议分开标示发表值与本次结果，并把同协议控制表放在主位；不要仅靠小字表注抵消统一排行榜的视觉暗示。若需要更紧凑的4页稿，可将宽表保留于完整工作稿/仓库，主文改域级表，这是版式建议而非本次擅自改动。

## 9. 暂按ICASSP短稿的组织方案

以此前讨论的ICASSP 2027作工作假设。2026-09-12核对的[作者指南](https://2027.ieeeicassp.org/author-guidelines/)限制技术内容最多4页，第5页可仅放参考文献；[日期页](https://2027.ieeeicassp.org/important-dates/)列出全文截止为2026-09-16。具体截止时区以投稿系统为准，不能从网页装饰性时间推断。

推荐正文保持“一个问题、一个方法、两层验证”：

| 部分 | 建议内容 |
| --- | --- |
| 引言与相关工作，约0.7页 | STALL/D3/SPLIT之后还未回答的局部高维方向问题；一句方法与两项贡献 |
| 方法，约0.9页 | 局部D2与真实二次型为核心，Global/CDF/FC作为已定义支撑；一张流程图 |
| 设置与核心表，约1.2页 | 23单元、三域Average、AP-real、真实预算；同协议控制及必要方法级背景 |
| 稳定性和边界，约0.9页 | 新池与位置匹配的关键区间图/小表，观察及压缩反例 |
| 结论，约0.3页 | 与数据一致的增量与边界 |

页数是排版预算，不是已经渲染通过的4页PDF。建议从完整证据稿提炼出两张核心表和一到两张小图，不把当前十余张分析表全部缩字体塞入正文。关键结果必须在技术页内成立；尚未确认补充材料机制时，不将必要证明寄托给假设存在的无限附录。

主文比较表可以用现表3a为骨架，补一行位置数匹配；稳定性用本次增量图或紧凑区间表。源等权与均值替换等持平结果用一段文字带出处即可。原文背景宽表若保留，需要相应减少其他重复表格。

ICASSP[投稿说明](https://2027.ieeeicassp.org/paper-submission-instructions/)要求交代与先行工作的关系，不要求单独成节。短稿可将相关工作融合进引言，而不是挤占一页罗列文献。最终按该会议模板核对作者信息、引用及必要声明，不能默认不同会议采用相同匿名规则。

若实际目标是ICLR，组织原则仍成立，但贡献增量性和跨域证据的风险更大。其[评审指南](https://iclr.cc/Conferences/2027/ReviewerGuidelines)强调问题、动机、证据与新知识价值，并不把未达到SOTA本身作为拒稿理由；这也不意味着“小提升加大量消融”就足够。当前已有组件各自有先例，外部失败域明确，文字整理无法替代更广泛的新知识或确认数据。这里的会议适配判断是研究建议，不是录用概率承诺。

## 10. 投稿前的有限行动

**优先整理，不再为制造明显消融而启动新模块。** 当前表示、位置预算、新真实视频池、观察交互、重编码已经完成，没有必要把它们当待办再跑一次。

建议顺序：

1. 冻结当前方法和23单元数据身份，用新池结果更新摘要的主张强度；保留AP未确认与域间反转。
2. 按核心问题重排引言、方法和实验，合并重复表，将运行/数据工程细节留在独立规范文档。
3. 从未舍入CSV生成最终表格与差值图，核对Average、AP正类、视频/源数与百分比单位。
4. 处理主表发表值与自算值的协议边界；若要主张方法级全面优越，仍需相应公平比较，不能用现有控制替代该证据。
5. 按正式模板渲染、检查可读性和篇幅，保留可访问的分生成器结果与配置。未核实的外部配置不要临时拼进主表。

可以用于回复“消融小”的核心句式是：

> 我们不要求每个实现选择均提高分数；核心表示通过匹配对照和参考重拟合验证，而预算、均值和来源控制用于排除替代解释。较小但重复的增量支持有限结论，未重现的模块不进入主方法。

本轮交付为投稿组织建议与现有证据的可视化，不改变算法、不新增GPU实验、不代替作者最终审阅或实际提交。

## 11. 近期免训练论文的价值定位与本稿修订

2026-09-12定向核对七篇论文，重点阅读摘要、引言贡献、方法、主要结果和关键消融，并查看实际PDF表格。以下是围绕本稿的比较，不是穷尽式综述；图像论文只提供方法背景，不作为已跑的视频基线。

这些工作的中心分别是时间波动、过度连贯、联合似然、局部编辑、预训练不变性、条件真实分布和统计解释。值得借鉴的是“问题—统计设计—直接控制”的关系，不能将别人的泛化或鲁棒性结论直接写到本方法名下。

### 11.2 本文应凸显的价值

**在空间汇总或标量压缩之前，保留逐位置二阶方向，用真实分布定义代价，再汇总证据。**

D2规定时间关系，逐残差归一化保留方向，真实协方差规定方向代价，位置平均形成视频证据。这些步骤共同构成方法；单独使用D2、Patch或Gaussian不是新的统计工具。

对应的证据分三层：

1. **同信息预算的补充。** 表II-A的Global与Full使用同一批目标真实片段和窗口，Average由0.865/0.872变为0.874/0.877；Local-only显示其补充角色。
2. **先测量后聚合。** 表II-B匹配拟合位置数后，逐位置D2相对pooled仍提高约0.020/0.021，CDF前的原始分支排名也有增量，削弱“只是拟合向量更多”的解释。
3. **阶次与重复性。** 表II-C检验D1及局部标量，表III再更换真实拟合池；五次模型指标求均值，保留逐域差异及AP区间跨零。

方法中的二维能量示例只解释同样长度可以具有不同真实代价，不是生成视频物理模型。离散项恒等式解释固定表示和度量下的聚合差别，不能直接推出实际pooled的AUC必然较低。

SPLIT的TTR、LSMI也涉及方向关系；区别应精确到**相对真实参考的高维二阶方向度量**。指定SPLIT v1与作者代码没有单独FrameNorm模块，不将未经原文核实的模块写入比较。
