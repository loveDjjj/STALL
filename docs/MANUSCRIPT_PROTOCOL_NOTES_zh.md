## 2. 原文的短视频规则及我们的实现

原文5.1与附录C.2/C.3明确规定：常规16帧；HotShot-XL、MoonValley采用1秒、8 FPS、8帧，与同样1秒的真实视频比较。MoonValley实际视频长度在Table 6中为1.82秒，评价截取1秒，并非所有文件恰为1秒。

原文附录将这些短生成器排除在消融之外；**本轮按用户要求扩展消融范围，全部23单元**，不再保留20单元作为新消融的默认范围。

官方公开代码：

- video_index.py生成独立1/2/3/4秒窗口；不足16帧时2秒索引为空，但可能有1秒索引。
- 官方1秒窗口是seed42的第一次随机抽样；2秒窗口是随后一次抽样。
- README要求短视频使用duration=1；默认duration=2只覆盖其余10/8个生成器。
- 低于8 FPS不重复帧上采样。
- 官方STALL加载NPZ中的Gaussian/CDF，不随duration另行重拟合。

据此，官方短视频复现保持原NPZ。我们的方法保持现有目标Gaussian，为8帧输入重建对应GS/GT窗口CDF、Local视频CDF与独立阈值。没有把改过参考的检测器称作原版STALL。

| 环节 | 长视频 | 新短视频 |
| --- | --- | --- |
| 输入 | 16帧、名义8 FPS | 8帧、名义8 FPS |
| Local D2 | 每网格14项时间差分 | 每网格6项时间差分 |
| 观察 | FC/Uniform，K1/K3受控 | 一条共同1秒片段；四配置退化为同单窗 |
| 真实对照 | 同一16帧评价规则 | 同一8帧评价规则 |
| Gaussian | 已冻结目标参数 | 相同目标参数 |
| 本方法参考 | 原16帧对应参考 | 同身份VATEX独立8帧参考 |
| 官方STALL参考 | 官方NPZ | 同一官方NPZ |

1秒/2秒片段使用不同评价ID，但保留原始源组。区间重抽样时它们共享权重，不被当作独立真实来源。部署时不能先知道真假再决定窗口长度；论文中的真实1秒裁剪是与短视频基准配对的控制条件。

当前Global长窗CDF仍来自Uniform首窗，短窗来自共同1秒规则；不把这种长度扩展宣称为解决了所有选择器/时长分布偏移。

## 5. AP、Average与统计口径

官方论文文字写generated为AP正类，但官方metrics.py对STALL的HIGHER_IS_REAL分数使用real标签调用average_precision_score。我们沿用这个实际实现，即AP-real；AP-fake另外导出，不能用1−AP-real换算。

发表六个检测器的数字按报告保留，不假装从公开表就能恢复每列AP正类。正式稿应在表注说明这一冲突及本次口径。

论文中的总体Average先域内生成器等权，再三数据集等权。引用方法的Average照录原文，其汇总口径尚未完全核实；不声称名称相同即证明口径一致。当前论文统一定义为：

$$
\mathrm{Average}=\frac13\sum_d\frac1{J_d}\sum_jm_{d,j}.
$$

指标、平均、差值与区间都从未舍入数计算，最后显示三位。原文两位数补零不增加精度。接近零的CI边界可能显示0.000，必须依据未舍入数说明“大于零但接近零”或“跨零”，不能依据显示值判断。

区间：每协议19组、每组1000次源组Poisson配对bootstrap，历史产物保留两种汇总，但论文只使用三数据集等权结果；同一real源的两种裁剪共享权重。区间条件于固定拟合参考，未校正全部历史模型探索或参考重拟合的不确定性。

最终官方配对版本Local两项区间均为正，但AP下界很小；中间旧配对版本AP跨零，体现真实样本配对敏感性。不能混用两个版本的结论。更精确数值与全部区间在[CI表](../results/paper_complete/confidence_intervals.csv)。
