## 2026-08-20 主实验诊断（非正式结果）

本轮输出包含 21,421 条无重复、无缺失的逐视频分数，覆盖 ComGenVid 4,298 条、
VideoFeedback 3,500 条和 GenVideo 13,623 条。缓存评分本身完成，但在 paired bootstrap
阶段中断，因此运行状态不是 `completed`。

当前 `dataset_metrics.csv` 是所有生成视频直接合并后的 pooled 指标：ComGenVid
AUC/AP 为 0.8965/0.7485，VideoFeedback 为 0.7231/0.3549，GenVideo 为
0.8462/0.8555。它不等同于论文约定的按生成器宏平均口径，尤其 AP 会因真假比例而变化；
按生成器宏平均的 AP 分别为 0.8365、0.8192、0.9788。

更关键的是，Global 在第二级视频 CDF 后近乎失去排序信息：其 AUC 从窗口 CDF 聚合后的
0.8616/0.8531/0.7799 下降到 0.5757/0.5917/0.5020；VideoFeedback 的 Global 视频分数仅
有 3 个取值，3,498/3,500 个视频为 0。最终分数因而基本只反映 Local 分支，不能与
`paper/` 中的历史表格或任何基线作正式比较。

### 根因与修复

问题不在缓存、窗口采样或标签：严格缓存的 DINO 全局/patch 张量格式、校准与评测的视频
身份隔离以及 K=3 窗口索引均已核验。根因是旧实现把 1024 维经验协方差的所有正特征方向
都用于白化，只在分母加 `1e-5`。VideoFeedback Global Spatial 的校准协方差尾部存在约
`1e-6` 的特征值，白化会将该方向放大数百倍；校准视频参与了参数拟合，分数分布相对较高，
未见评测真视频则普遍低于校准经验 CDF 的最小值。窗口 CDF 的 0 再经过视频级 CDF，导致
Global 分支大量并列为 0。

当前 `benchmark.yaml` 已显式设为 `method.covariance_estimator: oas`。OAS 只使用同一批
real-only 校准特征，以数据驱动方式将协方差向等方差目标收缩，不读取评测集标签、特征或
结果。真实 VideoFeedback 校准缓存的健康检查显示，修复后四个白化矩阵均为有限值，条件数
依次为 Global Spatial 33.17、Global T1 6.21、Patch Spatial 238.56、Patch Temporal 27.07。
这说明此前 Global Spatial 的数值病态已解除；正式效果仍必须以完整重跑后的结果为准。
