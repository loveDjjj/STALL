# Pre-U0 release 文档

本目录冻结 locked U0 之前的 dataset-specific score-CSV 发布材料。文档中的
`docs/restructure/`、旧校准参数和旧结果路径按当时布局保留，用于复现实验考古；
它们不是当前协议或结果的事实来源。

当前入口：

- 协议：`docs/CURRENT_PROTOCOL.md`
- 结果状态：`docs/RESULT_STATUS.md`
- 项目治理：`docs/PROJECT_ORGANIZATION.md`
- 当前文件导航：`FILE_STRUCTURE.md`
- locked verifier：`tools/verify_u0_locked_release.py`

历史兼容验证器位于
`research_archive/tools/pre_release_assets/verify_alpha_stalled_release.py`，公开旧命令
`tools/verify_alpha_stalled_release.py` 只是其薄包装器。
